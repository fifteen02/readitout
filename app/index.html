Run free voices locally (Kokoro)

One-time setup. Voices then run on your machine with no key and no cost.

  1. Install Docker, then run one of these: CPU — Mac (Apple Silicon) & any machine
    docker run -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:latest
    GPU — NVIDIA only (Linux / Windows, not Mac)
    docker run --gpus all -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-gpu:latest
  2. Leave that running. Keep the URL above as http://localhost:8880/v1.
  3. Hit Preview voice on the Listen panel to test it.
